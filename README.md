# 📊 Analisando Dados de um Dashboard de Vendas no Power BI

---

## 📖 Introdução

Este projeto foi desenvolvido como parte do desafio **"Analisando Dados de um Dashboard de Vendas no Power BI"** da DIO.

O objetivo foi reproduzir as páginas construídas durante o curso e desenvolver uma página adicional com novos visuais para análise de desempenho comercial, explorando indicadores de vendas, lucro e segmentação de clientes.

Durante o desenvolvimento foram aplicados conceitos fundamentais de Business Intelligence, modelagem de dados e construção de dashboards interativos utilizando o Power BI Desktop.

---

## 🎯 Objetivos do Projeto

- Desenvolver um dashboard de vendas utilizando Power BI.
- Explorar indicadores de vendas, lucro e unidades comercializadas.
- Criar visualizações geográficas utilizando mapas.
- Analisar o comportamento dos segmentos de clientes.
- Praticar organização e apresentação de relatórios analíticos.
- Consolidar conhecimentos em visualização de dados.

---

## 📊 Páginas Desenvolvidas

### Página 1
Dashboard inicial contendo os principais indicadores e análises apresentadas durante o curso.

### Página 2
Relatório de Vendas Considerando Países e Lucro:

- Soma de Sales
- Soma de Units Sold
- Soma de Profit por País
- Soma de Sales por País
- Média de Profit por Ano e Mês

### Página 3
Página criada para o desafio:

- 🌎 Mapa de Vendas e Unidades Vendidas por País
- 💰 Mapa de Lucro por País
- 🥧 Participação do Lucro por Segmento
